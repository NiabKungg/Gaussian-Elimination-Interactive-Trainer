ระบบเรียนรู้และฝึกทำโจทย์การขจัดแบบเก๊าส์ (2x2 & 3x3)

📘 ทำความเข้าใจการขจัดแบบเก๊าส์ (Gaussian Elimination)

ส่วนนี้สรุปแนวคิดพื้นฐานของการแก้ระบบสมการเชิงเส้นโดยใช้วิธีขจัดแบบเก๊าส์ ซึ่งเป็นกระบวนการแปลง **เมทริกซ์แต่งเติม (Augmented Matrix)** ให้อยู่ใน **รูปแบบขั้นบันไดตามแถว (Row Echelon Form: REF)** ด้วย **การดำเนินการตามแถวขั้นมูลฐาน (Elementary Row Operations: ERO)** จากนั้นจึงหาคำตอบด้วย **การแทนค่าย้อนกลับ (Back-substitution)**

1

เมทริกซ์แต่งเติม (Augmented Matrix)

เขียนสัมประสิทธิ์และค่าคงที่ของระบบสมการ AX = B ให้อยู่ในรูปเมทริกซ์ผสาน [A | B] เพื่อเตรียมคำนวณ

[ a1 b1 | c1 ]
[ a2 b2 | c2 ]
2

การดำเนินการตามแถว (ERO)

ใช้ 3 กฎทองเพื่อแปลงเมทริกซ์โดยไม่เปลี่ยนคำตอบของระบบสมการ:

  • 1. สลับแถว (Ri ↔ Rj)
  • 2. คูณแถวด้วยสเกลาร์ c ≠ 0 (c Ri)
  • 3. บวกพหุคูณแถว (Ri + c Rj)
3

แทนค่าย้อนกลับ (Back-substitution)

เมื่อได้รูปขั้นบันไดสามเหลี่ยมบนแล้ว ให้แทนค่าตัวแปรจากแถวล่างสุดย้อนกลับขึ้นไปหาตัวแปรแถวบน

z = k → y + c(z) = m → x = ...
